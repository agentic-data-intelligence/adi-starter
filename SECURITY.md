# Security

## Reporting a vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Use [GitHub private vulnerability reporting](https://github.com/agentic-data-intelligence/adi-starter/security/advisories/new), or email <security@agentic-data.com> with a description of the vulnerability and steps to reproduce.
3. Allow time for us to address the issue before disclosing it publicly.

We will acknowledge your report and work on a fix. Thank you for helping keep this project secure.
